## [Unreleased]

### Fixed
- **Срок TLS-сертификата больше не зависит от локали.** `getpeercert()["notAfter"]` — это
  RFC-2822 (`Jan  5 00:00:00 2035 GMT`); прежний `strptime("%b %d %H:%M:%S %Y GMT")` под
  не-английской `LC_TIME` падал с `ValueError`, и проверка истечения сертификата молча
  выключалась на всех мониторах.
- **Сбой записи результата не оставляет монитор в `status = running` навсегда.** Если
  монитор удалён во время проверки, `record_check_result()` откатывает транзакцию и
  возвращает `None` вместо `IntegrityError` в лицо пользователю; при другой ошибке записи
  `execute_task_immediately()` восстанавливает прежний статус, поэтому планировщик
  продолжает видеть монитор в `get_due_tasks()`.
- **Мусор в числовых переменных окружения больше не роняет старт.** Пустое значение даёт
  значение по умолчанию, а нечисловое — `ValueError` с именем переменной вместо
  `invalid literal for int()`.
- **`/add` принимает многословные названия.** Эндпоинт ищется по `://` (или по точке в
  хосте), а не по позиции, поэтому `/add Мой платёжный API https://api.example.com/health 5`
  создаёт монитор с полным названием вместо обрезанного «Мой» и мусорного эндпоинта.
- **Сайт-блокнот: копирование команды деплоя.** Отклонённое `navigator.clipboard` больше не
  остаётся необработанным rejection — есть `execCommand("copy")` фолбэк и явный тост, если
  буфер недоступен; отправка пустого эндпоинта теперь объясняется, а не молчит.

### Changed
- `BOT_VERSION` стал единственным источником версии: User-Agent пробника и заголовки
  `/start` и `/help` больше не расходятся (было `tt_bot-monitor/2.1`).
- `README.ru.md`: восстановлены разрушенные inline-код спаны.

## [2.3.0] — 2026-11-22

### Added
- **Telegram Bot Ops UI/UX**:
  - ASCII-спарклайн задержки (`▁▂▃▄▅▆▇█`) и шкала SLA (`█████████░`) в карточке монитора и в `/stats`.
  - Команда `/expect ID строка|-` для настройки проверки подстроки в HTTP-ответе прямо из чата (с IDOR-защитой и отображением в карточке).
  - Режим обслуживания прямо в списке мониторов: `⏸ Пауза всех` (`menu:pause_all`) и `▶️ Запустить всех` (`menu:resume_all`).
- **Жёсткий UI/UX сайта-блокнота (`docs/index.html`, `docs/showcase/index.html`, `docs/og-card.png`)**:
  - Верхняя телеметрическая линейка (`SYS: NOMINAL/DEGRADED`, счётчик узлов, SLA, режим, кнопка `? HOTKEYS`).
  - Анимированная SVG-шина данных под 5 узлами архитектуры + быстрые клавиши `1–5` для инспекции узлов и `?` для шпаргалки горячих клавиш.
  - Фильтры чек-листа (`ALL / UP / DOWN / HTTPS / TCP`) и кнопка реального скачивания **sanitized CSV** прямо с главной страницы.
  - В витрине: полная поддержка `/expect`, `Пауза всех / Запустить всех`, спарклайн задержки, шкала SLA и фильтрация по уровню (`ALL / INFO / WARN / ERROR`) + копирование в **JSON Logs**.

## [2.2.0] — 2026-11-22

### Added
- **Telegram UX v2.2**: живая сводка (`UP / DOWN / SLA 24ч`) прямо в главном меню, per-monitor SLA 24ч и P95 в карточке монитора, кнопка **`🔔 Порог 1..3`** (`task:thr`), кнопка **`🔁 Перепроверить упавшие`** (`menu:run_failed`) в `/incidents`, индикация шагов FSM (`Шаг 1/5 .. 5/5`) и умный `fallback_message` без тупиков (сырой URL в чате сразу предлагает готовую команду `/add`).
- **Жёсткий инженерный UI/UX сайта-блокнота (`docs/index.html`, `docs/showcase/index.html`, `docs/og-card.png`)**:
  - Командная палитра **`⌘K` / `Ctrl+K`** и тактильные тосты на обеих страницах.
  - Физические индекс-закладки справа, нумерация строк на полях, жёсткие `2px` контуры и `tabular-nums`.
  - Кликабельная диагностика каждой строки чек-листа (10-слотовая шкала, статус SSRF/TLS, ручной сбой/восстановление узла) и график latency с линией SLA `100 мс` и P50/P95.
  - В витрине: чат-фид с исходящими сообщениями, модалка `show_alert=True` для теста **IDOR-атаки (`user_id=9999`)**, 3-вкладочный инспектор (**Execution Trace** / **SQLite WAL** / **JSON Logs**) и сравнительная таблица `v1.0 → v2.2`.
- **`AGENT_PROMPT.md`** — готовый промпт для кодинг-агента в пару к `AGENT_UPDATE_INSTRUCTIONS.md`.
