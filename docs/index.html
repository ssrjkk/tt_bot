Возможности

Бот берёт на себя рутину приёма лабораторных: от команды в чате до готовой таблицы для преподавателя.

Создание задач в чате /task

Преподаватель создаёт задачу прямо в Telegram: название и адрес сервиса — остальное бот делает сам.

Асинхронная очередь asyncio

Работы не ждут друг друга: пул исполнителей на asyncio разбирает очередь параллельно, пока бот остаётся отзывчивым.

Проверка доступности сервисов

Перед приёмом работы бот проверяет, отвечает ли указанный адрес, и честно пишет результат — доступен сервис или нет.

CSV-отчёты .csv

Результаты проверок выгружаются в CSV для преподавателя: таблица открывается где угодно, от Excel до Google Sheets.

Статусы и история

Каждая задача проходит понятные статусы, а вся история остаётся в SQLite — можно вернуться и посмотреть, что было.

Лёгкий деплой на любой машине

Python 3.11, aiogram 3 и SQLite — ничего лишнего. Бот поднимается на любой машине, от старого ноута до дешёвого VPS.

Как это работает

Четыре шага от задачи до отчёта

Шаг 1

Создание задачи

Команда в чате: название работы и адрес сервиса, который нужно проверить.

Шаг 2

Очередь asyncio

Задача попадает в очередь; исполнители разбирают её без блокировки бота.

Шаг 3

Проверка сервиса

Бот обращается по адресу и фиксирует, отвечает ли сервис, — результат честный.

Шаг 4

CSV-отчёт

Итоги проверок выгружаются в CSV — преподаватель получает готовую таблицу.

Запуск

Клонировать и запустить

Понадобятся Python 3.11+ и токен от @BotFather. Переменные окружения и полная инструкция — в README репозитория.

git clone https://github.com/ssrjkk/tt_bot.git
cd tt_bot
pip install -r requirements.txt
# токен и путь к базе — в переменных окружения
export BOT_TOKEN="your_bot_token_here"
export DB_PATH="coursework_var18.db"
export WORKERS_COUNT=3
python -m src.main
