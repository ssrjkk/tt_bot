Задачи и проверки — в одном чате

Создаёте задачу с привязкой к эндпоинту, бот гоняет проверки через пул асинхронных воркеров и отдаёт аналитику: сколько выполнено, где ошибки, какой средний latency. Отчёт выгружается в CSV.

Возможности

От постановки задачи до отчёта

Полный цикл в Telegram: постановка через диалог, выполнение воркерами, хранение и аналитика. Без отдельной панели.

FSM-диалог

Создание задачи пошагово: название, категория, эндпоинт, приоритет. Конечный автомат не даёт пропустить шаг.

Четыре категории

Backend API, QA AutoTest, RPC Node, DevOps / VPS — задачи разделены по типу цели.

Пул воркеров

Проверки выполняются асинхронно через asyncio.Queue: несколько целей проверяются параллельно, а не по очереди.

SQLite WAL

Хранение в SQLite с WAL-режимом, индексами и кэшем 64 MB — быстро и без отдельного сервера БД.

Аналитика

Сводка: всего задач, выполнено, в ожидании, ошибки и средний latency по проверкам.

Экспорт в CSV

Реестр задач выгружается в CSV одним действием — для отчёта или further-обработки.

Запуск

Развёртывание за команду

Python 3.11+, aiogram 3 и aiosqlite. Запуск в Docker или через systemd — бот сам поднимает БД и воркеров.

Python 3.11+ aiogram 3 aiosqlite asyncio pytest Docker systemd
terminal
$ git clone https://github.com/ssrjkk/tt_bot
$ cd tt_bot
# токен бота в .env
$ docker compose up -d
