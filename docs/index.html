стр. 1

Задачи: от «сдать» до «сдано»

Сценарий приёмки построен на FSM: пользователь называет лабу → выбирает категорию → прикладывает файл или ссылку → задача появляется в списке со статусом. Статус меняется колбэком, напоминание приходит до, в день и после дедлайна.

  • создание задачи за 3 сообщения, без форм и команд
  • статусы: новая → в работе → сдана, смена колбэком
  • напоминания о дедлайне — до, в день и после
  • мониторинг URL — бот сам проверяет и логирует

Поднимается за пять минут

Два пути — оба описаны в README без догадок: Docker (volume /data) или systemd (venv в /opt, юнит с переименованием). sqlite работает под WAL — «database is locked» при двух воркерах исключён.
